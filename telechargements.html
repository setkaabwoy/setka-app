📥 Zone de Téléchargement (.MP3)

⚠️ Comment télécharger les sons sur ton appareil

Clique sur le bouton « Télécharger » à côté du morceau.
Si le son s'ouvre sur une page noire dans ton navigateur au lieu de se télécharger directement :
  • Android :
    • Mozilla : reste appuyé sur le lecteur puis clique sur « Enregistrer le fichier ».
    • DuckDuckGo ou Chrome : appuie sur les trois petits points (⋮) puis sur « Télécharger ».
  • iPhone (Safari) : appuie sur les trois petits points (⋮) en bas à droite ➔ Partager ➔ trois petits points (⋮) ➔ Enregistrer dans Fichiers ➔ Enregistrer.
  • Windows : appuie sur les trois petits points (⋮) du lecteur puis sur « Télécharger ».
  • Mac : fais un clic droit sur le lecteur puis sélectionne « Download Video As... » ou « Download Video ».
