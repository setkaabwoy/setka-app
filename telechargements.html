⚠️ Comment télécharger les sons sur ton appareil

Clique sur le bouton « Télécharger » à côté du morceau.

Si le son s'ouvre sur une page noire dans ton navigateur au lieu de se télécharger directement :

Android :

  • Mozilla : reste appuyé sur le lecteur puis clique sur « Enregistrer le fichier ».
  • DuckDuckGo ou Chrome : appuie sur les trois petits points (⋮) puis sur « Télécharger ».

iPhone (Safari) :

  • Appuie sur les trois petits points (⋮) en bas à droite ➔ Partager ➔ trois petits points (⋮) ➔ Enregistrer dans Fichiers ➔ Enregistrer.

Windows :

  • DuckDuckGo : appuie sur les trois petits points (⋮) du lecteur puis sur « Télécharger ».
  • Mozilla : Clic droit sur le lecteur puis appuyer sur "enregistrer le fichier audio sous ...".
  • Chrome : appuyer sur les trois petits points (⋮) puis sur "télécharger".

Mac (Safari) :

  • Fais un clic droit sur le lecteur puis sélectionne « Download Video As... » ou « Download Video ».
